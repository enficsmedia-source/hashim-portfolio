# Hashim Portfolio (Next.js)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

- Edit all content (projects, services, reviews, FAQ, CV link) in `lib/content.js`.
- Put your CV at `public/cv.pdf` and set `CV_URL = "/cv.pdf"`.
- Images live in `public/images`, the reel in `public/video`.
- Styles are in `app/globals.css`. Deploy for free on Vercel (import the folder / GitHub repo).
